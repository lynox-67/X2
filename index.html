From source file to paying buyer.

01

Upload your script

Create a script in the panel and drop in a .lua or .luau file. Each publish is obfuscated and added to the release history, so you can see what shipped and when.

02

Issue licenses

Create a license for each buyer with an expiry date and an HWID limit. The same table lets you ban or reinstate a license, reset its HWIDs, change its expiry or delete every expired one at once.

03

Buyers run the loader

The panel gives you a two line loader with the buyer's license filled in. They paste it into their executor, and the loader checks their license and device before your script runs.

What happens to your script after you press publish.

VM obfuscation
Every build runs through the obfuscation engine before it ships. Buyers never receive your readable source, and you don't need a separate obfuscator subscription.
HWID-bound licenses
A license works on as many devices as you allow, usually one. A leaked key fails on anyone else's machine.
One loader for every update
Publish a new release and buyers get it the next time they run the loader. Nobody needs a new link.
Execution stats
The dashboard counts executions and active users per script, day by day, so you can see when an update lands well.
